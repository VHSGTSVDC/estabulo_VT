# v3.0.2 — Interface Responsiva

Alterações visuais:
- nomes das abas substituídos por símbolos relacionados;
- nome completo aparece como tooltip ao passar o mouse;
- `aria-label` mantido para acessibilidade;
- removida completamente a rolagem horizontal da navegação;
- abas quebram automaticamente em novas linhas;
- conteúdo interno não pode mais forçar rolagem lateral;
- toolbar, formulários e grids se reorganizam em resoluções menores;
- catálogo de acessórios vira layout vertical em telas estreitas;
- cards e estatísticas se adaptam à largura disponível.
