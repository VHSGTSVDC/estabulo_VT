# v2.5.0 — Otimização, segurança e preparação para release

## Proteção de eventos
Rate limit no servidor para:
- compra de cavalo;
- compra de acessórios/ferraduras;
- venda;
- transferência;
- abrir alforje;
- ações do cavalo;
- save de estado;
- atualização de necessidades;
- requisições repetidas da NUI.

## Persistência
`saveState` agora:
- valida propriedade novamente;
- rejeita NaN/infinito;
- limita vida/stamina/necessidades/XP/treino;
- limita coordenadas absurdas;
- atualiza usando id + identifier + charidentifier.

## Desempenho
- monitor de saúde usa intervalo adaptativo;
- monitor de morte dorme mais quando não há cavalo ativo;
- logs repetitivos de necessidades ficam atrás de `Config.Performance.debug=false`;
- abastecimento de água do rancho limitado a 100 itens por chamada.

## Banco
A migração cria índices nas consultas mais usadas:
- proprietário/personagem;
- cavalo principal;
- death_state;
- rancho;
- estado crítico;
- gestações;
- mercado.

SQL:
`sql/MIGRATE_V2.4_TO_V2.5_OTIMIZACAO.sql`

Não remove funcionalidades e não apaga dados.
