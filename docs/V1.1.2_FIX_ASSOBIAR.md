# v1.1.2 — Correção do assobio

- `/assobiar` busca o cavalo principal diretamente no MySQL.
- Não depende mais de a lista local `Horses` já ter carregado.
- Se já houver cavalo ativo, ele recebe uma nova tarefa para ir até o jogador.
- O cavalo solicitado nasce a uma distância mínima de 12m e caminha até o jogador.
- Mantém acessórios e atributos ao chamar.
- Adicionados logs:
  - `ASSOBIO: enviando cavalo`
  - `ASSOBIO SPAWN OK`
  - `ASSOBIO CHAMAR`
- Não requer SQL.
