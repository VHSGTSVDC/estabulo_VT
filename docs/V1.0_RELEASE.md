# LRRP_Stables v1.0.0

## Atualização a partir da v0.9
Execute somente `sql/migrate_v0.9_to_v1.0.sql`. Não apague `lrrp_horses`.

## ACE staff
```cfg
add_ace group.admin lrrp.stables.admin allow
```

## Webhook opcional
Em `config.lua`, preencha `Config.Release.webhookUrl`. Vazio = desativado.

## Permissões de rancho
O proprietário pode adicionar `manager`, `worker` ou `guest`. Gerentes podem construir; workers podem executar manutenção.

## Editor de estrutura
No menu Release 1.0, clique em editar/construir. Controles: W/S mover, A/D girar, ENTER confirmar, BACKSPACE cancelar.

## Treinos por disciplina
Corrida, resistência, manejo e tambores são persistidos em `lrrp_horses.disciplines`.

## Ferraduras
`horseshoe_durability` vai de 100 a 0 e diminui conforme distância montada. A durabilidade é persistente.

## Auditoria
Ações da camada v1.0 entram em `lrrp_stable_audit_logs`. O painel staff mostra as 30 mais recentes.
