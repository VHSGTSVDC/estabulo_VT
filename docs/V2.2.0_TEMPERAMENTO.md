# v2.2.0 — Personalidade e temperamento

Personalidades:
- Calmo
- Corajoso
- Arisco
- Teimoso
- Energético

Efeitos:
- chance diferente de susto com disparos próximos;
- reação diferente ao susto;
- velocidade/resposta ao comando Seguir;
- Bonding 1–4 reduz progressivamente os efeitos negativos;
- personalidade fica persistida no MySQL.

Menu do botão direito:
- Temperamento mostra personalidade e descrição.

Comando:
- /temperamentocavalo

Execute uma vez:
sql/MIGRATE_V2.1_TO_V2.2_TEMPERAMENTO.sql
