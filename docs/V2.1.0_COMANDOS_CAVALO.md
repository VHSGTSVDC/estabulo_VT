# v2.1.0 — Comandos de comportamento

No menu do botão direito do cavalo:
- 🐎 Seguir-me
- ✋ Ficar
- 🌿 Pastar / andar livre
- 🚪 Mandar embora

Seguir:
- acompanha o jogador automaticamente;
- velocidade de resposta melhora com Bonding;
- para ao chegar perto.

Ficar:
- interrompe outras tarefas;
- mantém o cavalo parado.

Pastar:
- libera o cavalo para caminhar nas proximidades.

Comandos de teste:
- /cavaloseguir
- /cavaloficar
- /cavalopastar

Não requer SQL.
