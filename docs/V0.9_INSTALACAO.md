# LRRP_Stables v0.9

## Atualização da v0.8
Execute apenas `sql/migrate_v0.8_to_v0.9.sql`.

## Itens adicionais no VORP Inventory
- `hay_bale` — fardo de feno para estoque físico do rancho.
- `water_bucket` — balde de água para estoque físico do rancho.

Os itens antigos continuam necessários conforme `docs/ITENS_VORP_INVENTORY.md`.

## Staff
```cfg
add_ace group.admin lrrp.stables.admin allow
```

## Cavalos selvagens
Use `/cavaloselvagem` dentro de uma zona configurada para forçar um spawn de teste. Normalmente o sistema também mantém um cavalo local na zona quando o jogador está próximo.
