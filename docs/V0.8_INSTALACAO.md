# LRRP_Stables v0.8

## Dependências
- oxmysql
- vorp_core
- vorp_inventory

## server.cfg
```cfg
ensure oxmysql
ensure vorp_core
ensure vorp_inventory
ensure LRRP_Stables

# Staff do estábulo
add_ace group.admin lrrp.stables.admin allow
```

## Migração da v0.7
Execute `sql/migrate_v0.7_to_v0.8.sql`.

- `horsemeal`: ração usada também para estoque do rancho.
- `horse_trophy`: troféu físico das corridas multiplayer.
