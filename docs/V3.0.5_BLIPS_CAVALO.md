# v3.0.5 — Blips de Cavalo

## Blip 1 — Cavalo ativo
- símbolo de cavalo preso diretamente à entidade;
- acompanha o cavalo em tempo real no minimapa;
- usa o nome do cavalo como nome do blip;
- desaparece quando o cavalo é guardado/mandado embora;
- recriado automaticamente após respawn visual.

## Blip 2 — NPC de suprimentos
- símbolo de cavalo preso ao NPC;
- aparece no mapa/minimapa;
- recriado automaticamente se o NPC for recriado pelo watchdog.

Config:
Config.HorseBlips.activeHorse.enabled
Config.HorseBlips.activeHorse.blipHash
Config.HorseBlips.supplyNpc.enabled
Config.HorseBlips.supplyNpc.blipHash

Hash padrão de cavalo:
-1230993421
