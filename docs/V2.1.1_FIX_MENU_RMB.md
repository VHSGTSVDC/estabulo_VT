# v2.1.1 — Correção do menu contextual

Sintoma:
- botão direito era pressionado;
- NUI recebia foco antes de o clique terminar;
- o mesmo clique podia ser interpretado pelo HTML como clique fora;
- menu desaparecia imediatamente.

Correção:
- menu abre em `IsDisabledControlJustReleased`;
- não fecha mais por clique fora;
- ESC continua fechando;
- selecionar uma ação fecha depois de enviar o comando;
- foco NUI é liberado após a ação.

Mantém:
- Seguir-me
- Ficar
- Pastar
- Mandar embora
- cuidados e alforje

Não requer SQL.
