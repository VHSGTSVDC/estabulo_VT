# v1.8.0 — Profissão treinador

Jobs reconhecidos:
- horse_trainer
- trainer

Fluxo:
1. Dono abre Profissões.
2. Escolhe cavalo, disciplina e ID do treinador.
3. Treinador recebe Aceitar/Recusar.
4. Ao aceitar, $250 ficam reservados.
5. Treinador realiza minigame de 6 rodadas.
6. Nota mínima: 50.
7. Sucesso: treinador recebe $200; cavalo ganha nível da disciplina, XP e training.
8. Falha/timeout: dono recebe reembolso.

Disciplinas:
- Corrida
- Resistência
- Manejo
- Tambores

Cooldown por cavalo: 180 segundos.

Não requer SQL novo.
