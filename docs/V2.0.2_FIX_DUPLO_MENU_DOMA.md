# v2.0.2 — Remove menu duplicado após a doma

Causa encontrada:
- havia DOIS listeners para a mesma mensagem `wildName`;
- o listener antigo abria o modal genérico;
- o listener novo abria o modal dedicado;
- ao salvar o modal novo, o antigo permanecia por baixo e parecia uma segunda tela travada.

Correção:
- removido completamente o handler legado `wildName`;
- somente `wildNameModal` controla a nomeação;
- evento repetido com o mesmo token é ignorado;
- ESC do menu principal não interfere em overlays dedicados;
- foco é liberado ao salvar/cancelar.

Não requer SQL.
