# v1.3.1 — Correção do alforje / mover itens

Problema encontrado na versão de `vorp_inventory` da base SERVER_VT:

`ADD_CHAR_ID_PERMISSION_MOVE_TO` e `ADD_CHAR_ID_PERMISSION_TAKE_FROM`
retornam antes de aplicar a permissão quando `UsePermissions=true`.

Sintoma:
- custom inventory abre normalmente;
- jogador vê inventário e alforje;
- arrastar item para o alforje é bloqueado.

Correção:
- cada alforje continua exclusivo por `lrrp_horse_<ID>`;
- `UsePermissions=false` somente nesse custom inventory;
- propriedade do cavalo continua validada no servidor pelo `getOwned()`;
- caches de alforjes antigos são removidas da sessão e registradas novamente;
- `removeInventory` NÃO apaga os itens persistidos;
- armas continuam aceitas;
- não requer SQL.

Logs:
- `ALFORJE CACHE ATUALIZADA`
- `ALFORJE REGISTRADO`
- `ALFORJE ABERTO`
