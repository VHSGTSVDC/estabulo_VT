# v3.0.3 — NPC Loja de Suprimentos

NPCs adicionados:
- Valentine
- Blackwater
- Saint Denis
- Rhodes

Interação:
- aproxime-se;
- pressione G;
- escolha item e quantidade;
- pagamento via VORP;
- item adicionado ao VORP Inventory.

Itens padrão:
- water
- horsemeal
- horsebrush
- water_bucket
- horse_medicine
- horseshoe_kit

Preços e locais ficam em `Config.SupplyShop`.

Segurança:
- valida item no servidor;
- quantidade limitada a 25;
- rate limit de compra;
- checa saldo;
- reembolsa se o inventário falhar.

Não requer SQL novo.
