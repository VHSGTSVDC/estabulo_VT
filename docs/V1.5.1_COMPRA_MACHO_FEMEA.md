# v1.5.1 — Escolha de sexo na compra

Agora, ao clicar em Comprar:
- informe o nome;
- escolha ♂ Macho ou ♀ Fêmea;
- o sexo selecionado é enviado ao servidor;
- o servidor valida `male`/`female`;
- o valor é salvo na coluna `lrrp_horses.sex`.

Isso permite comprar propositalmente os animais necessários para reprodução.
Não requer SQL novo além da migração v1.5.0 já aplicada.
